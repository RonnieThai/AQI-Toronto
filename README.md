# AQI-Toronto
Air Quality Trend Tracker 

This project uses python and excel to organize and display the air quaility of Toronto within a couple of days.
It is useful to track the air quality of certain locations because it shows if it is healthy for humans to breathe in or if we need to take action.
Also being able to keep track of it shows sciencetist the trends of our air and shows if theres an abnomality. If there is then action needs to be taken

Uses pandas to read and import excel file
matplot to display the data in a graph
numpy to organize the data easily 

IMPORTANT
Make sure that the file of excel is being imported correctly or else it would not work
